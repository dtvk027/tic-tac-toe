A modern, responsive Tic Tac Toe web game with **Player vs Player** and **Player vs AI** modes, powered by the **Minimax algorithm** for intelligent AI gameplay.

## 🧠 How the AI Works

The AI uses the **Minimax algorithm** to evaluate possible game states and select the best move.

The algorithm considers:

1. Winning moves
2. Blocking the player's winning moves
3. Future game states
4. Draw positions

This allows the AI to make optimal decisions rather than choosing moves randomly.

## 🎯 Game Modes

### Player vs Player
Two players can play against each other on the same device.

### Player vs AI
Play against the Minimax-powered computer opponent.
